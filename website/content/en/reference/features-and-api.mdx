# Feature and API map

This page navigates the crate's public surface. Use [docs.rs](https://docs.rs/a3s-boot) as the source of truth for exact trait bounds, method signatures, and Rustdoc.

| Feature          | Default | Primary exports                                                                          |

## Feature selection rules

- Start with defaults and add a module only for a real boundary.
- A library crate should not force every Boot feature on downstream users.
- Inspect feature unification with `cargo tree -e features -p a3s-boot`.
- Run focused tests for production combinations, then `cargo check --all-features` for a release.
- Successful compilation of an external transport feature does not prove its broker is configured correctly.
